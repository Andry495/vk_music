# Отложенные задачи

## После авторизации

- [ ] **Отсекать рекламные вставки между треками**  
  Воспроизведение идёт из локального/офлайн кэша (скачанный аудиопоток), не из live-потока с рекламой.  
  При смене трека и при подготовке очереди полностью исключать ad-сегменты / рекламный поток VK Music (не буферизовать, не ставить в Media3 queue, не сохранять в кэш).  
  Детали реализации — после рабочего `AuthReady` + базового плеера/репозитория.
